# 제철밥상 PRD

## 1. 목표
- **한 줄 정의:** 제철밥상은 건강한 식단을 원하는 사람이 이번 달 제철 식재료로 만들 수 있는 저칼로리 레시피를 고를 수 있게 해준다.
- **해결할 문제:** 식단을 짤 때 지금 어떤 식재료가 제철인지 모르고, 그 식재료로 만들 수 있는 레시피와 칼로리를 한 번에 확인하기 어렵다.

## 2. 대상 사용자
- **주 사용자:** 건강한 식단을 원하는 사람 · 오늘이나 이번 주에 뭘 해 먹을지 정하려는 상황 · 제철 식재료로 칼로리를 생각하며 건강하게 먹고 싶어서
- **부 사용자:** 없음
- **사용 환경:** 모바일 우선 (mobile)

## 3. 핵심 과업
- 사용자는 이번 달 제철 식재료로 뭘 해 먹을지 정하려고 앱을 열고, 제철 식재료 하나를 골라 레시피별 칼로리를 비교한 다음, 마음에 드는 레시피의 상세 내용을 확인한다.
- 사용자는 다음 달(또는 다른 달)에 나오는 식재료가 궁금해서 메인에서 월을 바꿔 그 달의 제철 식재료를 확인한다.

## 4. 범위 (이번에 만드는 화면)

| 화면 | 목적 | 주 행동 |
|---|---|---|
| 메인 | 선택한 달의 제철 식재료 보여주기 (기본값: 현재월) | 월을 바꾸거나 식재료 하나를 선택한다 |
| 식재료 상세 | 선택한 식재료로 만드는 레시피 목록과 칼로리 보여주기 | 레시피 하나를 선택한다 |
| 레시피 상세 | 식재료 정보와 함께 레시피 내용(사진 포함) 보여주기 | 레시피 내용을 읽고 따라 만든다 |

### 화면별 표시 정보
- **메인**
  - 선택한 월 (기본값: 현재월, 예: 11월). 다른 달로 바꿀 수 있음
  - 해당 월 제철 식재료 목록 (최대 10개): 식재료명 / 사진
- **식재료 상세**
  - 선택한 식재료명
  - 레시피 목록 (식재료당 최대 5개): 레시피 사진 / 레시피명 / 칼로리
- **레시피 상세**
  - 식재료 상세 페이지 정보 포함
  - 레시피 내용 (사진 포함)

## 5. 제외 항목
최소 기능으로 먼저 만들고, 아래 기능은 나중에 붙인다.
- 로그인 / 회원가입
- 즐겨찾기 / 저장
- 검색
- 댓글 / 후기
- 식재료 구매 연결
- 칼로리 외 영양 정보 (탄수화물·단백질·지방 등)

## 6. 성공 기준
- **사용자 관점:** 메인 → 식재료 선택 → 레시피 상세까지 1분 안에 도달한다
- **시범 관점:** 모든 게이트 통과 · 걸린 시간과 재작업 횟수 기록

## 7. 참고 서비스 (선택)
- 미정

## 8. 데이터 (선택)

| 데이터 | 필드 | 비고 |
|---|---|---|
| 월 | 월(1~12) | 기본값은 현재월 |
| 식재료 | 식재료명, 사진, 제철 월 | 월당 최대 10개 |
| 레시피 | 레시피명, 사진, 칼로리, 레시피 내용(사진 포함), 연결 식재료 | 식재료당 최대 5개. 칼로리 단위는 kcal |

**상태 값**
- 선택한 월
- 선택한 식재료
- 선택한 레시피

## 9. 톤·브랜드 (선택)
